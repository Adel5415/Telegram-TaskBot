# Telegram-TaskBot
Телеграм-бот для управления задачами (to-do) с поддержкой дедлайнов, приоритетов, напоминаний и удобным интерфейсом.

Работает на Python и aiogram 3.x.

Все задачи сохраняются между перезапусками, бот поддерживает множество функций и интуитивно понятен даже новичку.

####📌 Основные возможности
-Добавление задач с текстом, дедлайном (датой и временем) и приоритетом.
-Просмотр задач со статусами, дедлайнами и приоритетами.
-Отметка задач выполненными.
-Удаление задач.
-Изменение текста задачи.
-Изменение дедлайна и приоритета.
-Поиск по задачам.
-Сортировка задач по дедлайну, приоритету и статусу.
-Очистка всех задач.
-Автоматические напоминания за 30 минут до дедлайна.
-Поддержка нескольких пользователей (у каждого свой список задач).
-Полная поддержка русского языка.

##💡 Использование
####Пиши своему боту в Telegram команды:

-/add <текст> [дд.мм.гггг чч:мм] [low|normal|high]
   -Примеры:
    /add сделать домашку 10.06.2026 21:00 high
    /add купить молоко
    /list — показать все задачи

-/done <номер> — отметить задачу выполненной
   -/done 2

-/edit <номер> <новый текст> — изменить текст задачи
   -/edit 1 купить чёрный хлеб

-/deadline <номер> <дата/время> — изменить дедлайн
   -/deadline 2 11.06.2026 18:00

-/priority <номер> <low|normal|high> — изменить приоритет
   -/priority 2 low

-/delete <номер> — удалить задачу
   -/delete 1

-/clear — удалить все задачи

-/search <текст> — найти задачи по ключевому слову
   -/search хлеб

-/help — справка по командам

##🔔 Напоминания и дедлайны
Если у задачи есть дедлайн, бот автоматически напомнит о ней за 30 минут до срока.
Напоминание придёт только один раз.
Поддерживаемые форматы даты/времени:
дд.мм.гггг чч:мм (например, 10.06.2026 20:00)
дд.мм.гггг (если время не указано, по умолчанию 00:00)
